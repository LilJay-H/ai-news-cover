## 为什么做它

**AI 的世界一天一个样**。新模型、新产品、新论文，一觉醒来可能就换了一批新闻。我想保持对 AI 领域的关注，但消息来源太分散了——公众号、抖音、小红书……我总是看不过来，然后就不想看了。

而我很喜欢的一位博主数字生命卡兹克正好做了一个 AI 新闻聚合站——**[AIHOT](https://aihot.news)**。这个产品很好地解决了信息来源分散与高质量信息筛选的问题，但每次打开电脑，都要打开浏览器、点开网页，才能看到一条条新闻……我总觉得，可以 **“再近一点”**。

让眼睛离新闻再近一点，让信息入口离人再近一点，让我离 AI 的最新动态更再近一点————于是，便有了 **AI news cover** 这个壁纸项目。它把卡神的 [AIHOT](https://aihot.news) 搬到了桌面上，变成**一张每时每刻都在更新的 AI 报纸**。

**[在线体验 →](https://liljay-h.github.io/ai-news-cover/)** 不用安装，打开就能看。

## 它是一张报纸，而不只是一个壁纸

我希望它看起来像一页有质感的报纸，而不是一个铺满文字的桌面。

- **两套选择**：**简约版**像一张印好的报纸，安静地铺在桌面上；**详细版**把精选、热点、日报收进三张卡片，适合想多看一点的人。当然，你可以随时切换两种预设~
- **排版**：报头、栏线、衬线字体、留白，让阅读回归简约与轻松，让文字间有呼吸的空间
- **动效**：每一次展开和收起都像在纸上翻动，东西从哪里来，就回到哪里去；参照 iOS 的手感打磨，快而不急
- **一眼、展开、细读，三步就到原文**：平时只看一眼标题；想多看，就把一栏在原地铺开；感兴趣的那条，再点开读摘要；最后一步，跳到 AIHOT 读原文。每一步都在桌面壁纸上完成

## 一些藏在纸里的小心思

- **会涨水的时间**：时钟的数字里装着水，一天过去多少，水就涨到多高
- **你不在的时候**：离开电脑一阵子再回来，桌上会多一张便签，告诉你刚才错过了什么
- **深夜的小卡片**：过了凌晨一点，它会轻轻劝你去睡。今天的新闻，明天还在
- **一个月前的今天**：日报右上角有一个小折角，翻过去，是一个月前的头条。在 AI 的世界里，一个月前常常已经像很久以前
- **一句有意思的话**：报头上每隔一阵会换一句话，有时是乔布斯，有时是苏格拉底
- **纸色会跟着时间变**：清晨、正午、傍晚，桌面的质感都不太一样

## 安装

到 [Releases](../../releases/latest) 下载：

| 你的电脑 | 下载 | 安装 |
|---|---|---|
| Windows（Lively 或 Wallpaper Engine） | `AI-news-cover-Setup.exe` | 双击运行 |
| macOS（Plash） | 即将支持 | — |

Windows 版会一起装上一个托盘小工具，让点开的新闻在浏览器里正常弹出。第一次运行时如果提示「未知发布者」，点「更多信息 → 仍要运行」即可。

也可以把 [INSTALL-AGENT.md](INSTALL-AGENT.md) 里的那段话发给你的 AI 助手（Claude Code、Codex 等），让它帮你装好。

## 数据来源与许可

新闻内容来自 **[AIHOT](https://aihot.news)** 的公开接口（AIHOT 以 MIT 协议开源：<https://github.com/KKKKhazix/AIHOT>），本项目已征得 AIHOT 作者同意开源分享。壁纸只实时读取，不保存、不转发新闻内容，每条新闻都链回原文。

代码以 [MIT](LICENSE) 协议开源；字体以 SIL OFL 1.1 授权，见 [`assets/fonts/`](assets/fonts/)。自己构建：`npm install && npm run build && npm run pack`。

有问题或想法，欢迎提 [Issue](../../issues)。
