# 字体与许可

壁纸里用到的字体都来自 npm 的 [fontsource](https://fontsource.org) 包，构建时打进 `dist/`，运行时不在线加载。
它们都以 SIL Open Font License 1.1（OFL）授权，允许自由使用、嵌入和再分发；许可全文随本目录附上，
`npm run pack` 生成的 zip 里也带一份（`licenses/`）。

| 字体 | 用途 | 许可文件 |
|---|---|---|
| Fraunces | 大时间、名次数字 | [OFL-Fraunces.txt](OFL-Fraunces.txt) |
| Noto Serif SC（思源宋体） | 标题、正文衬线 | [OFL-NotoSerifSC.txt](OFL-NotoSerifSC.txt) |
| Noto Sans SC（思源黑体） | 小字、说明 | [OFL-NotoSansSC.txt](OFL-NotoSansSC.txt) |
| Instrument Serif | 日期、名言署名 | [OFL-InstrumentSerif.txt](OFL-InstrumentSerif.txt) |
| Long Cang（龙藏体） | 留言条手写体 | [OFL-LongCang.txt](OFL-LongCang.txt) |
